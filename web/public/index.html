Run this build in Simulator

iOS Simulator only runs on a Mac with Xcode. Open this page on your Mac.

⬇ Download build

You need to be signed in to GitHub with access to this repository.

  1. Download the build. Safari unzips it automatically. In other browsers, double-click the downloaded zip.
  2. Open Simulator. Run open -a Simulator in Terminal, or in Xcode choose Xcode › Open Developer Tool › Simulator.
  3. Drag the .app onto the Simulator window. Simulator installs and launches it.

Double-clicking the .app does not work. It's an iOS Simulator build, and macOS can't run it directly.
